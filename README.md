## 2 Dimensional Tic-Tac-Toe for Windows

Play Tic Tac Toe in 2 dimensions with a friend on windows, this game is also known as ultimate Tic-Tac-Toe. You can either download the VinduMain.exe file, or build it yourself by.

running the tasks.json from vsCode or the following in the terminal

gcc VinduMain.c Vindu.c BrettGrafikk.c Tick_Tack_Toe_3X.c -o VinduMain.exe -luser32 -lgdi32 -static

Or your preferred compiler.

In the near future i may make a version for linux, and polish the graphics and maybe add some new features, and a more straightforward way to build the project.
